# Conversor de Monedas en Java

## Descripción

Este proyecto es una aplicación de consola desarrollada en Java que permite convertir monedas utilizando una API de tasas de cambio en tiempo real.
El usuario interactúa con el programa a través de un menú, eligiendo la conversión que desea realizar e ingresando el monto.

## Funcionalidades

El programa permite realizar las siguientes conversiones:

1. Dólar => Peso argentino
2. Peso argentino => Dólar
3. Dólar => Peso brasileño
4. Peso brasileño => Dólar
5. Dólar => Peso chileno
6. Peso chileno => Dólar
7. Salir del programa

El sistema solicita al usuario el monto a convertir y muestra el resultado en pantalla.

## Tecnologías utilizadas

* Java
* API ExchangeRate
* Gson para el manejo de JSON
* Programación orientada a objetos

## Cómo ejecutar el proyecto

1. Clonar el repositorio:
   git clone <url-del-repo>

2. Abrir el proyecto en IntelliJ IDEA o cualquier IDE compatible con Java.

3. Ejecutar la clase `Main`.
